about

kozzyx.org is a personal website built for the old-fashioned purpose of putting things on the internet because i wanted to.

i like technology, small useful tools, good design, strange corners of the web, and projects that do not require twelve dashboards to exist.

about this website

the site is plain html on purpose. every page should load quickly, work without javascript, and remain readable even if half the modern web ecosystem spontaneously catches fire.

you can browse around using the links above. there is no account, tracking profile, recommendation engine, or other machinery attempting to become emotionally significant.
