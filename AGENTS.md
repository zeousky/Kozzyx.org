# kozzyx.org

Static site for the archived KozzyX Discord bot. Edit here, then deploy through GitHub Pages.

## Deploy

1. Commit and push the website changes to the repository's `main` branch.
2. GitHub Actions publishes the repository root to GitHub Pages when `main` changes.
3. Confirm the live page on `https://kozzyx.org/` and any changed path after the workflow completes.

Do not use the Daki deployment client for this website; Daki is for the bot runtime only.

The public site is this brochure. The bot's web control center is served by the Node process, not by these files.
