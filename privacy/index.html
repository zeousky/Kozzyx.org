privacy

what it remembers

Last updated September 20, 2026. KozzyX is a server-management bot. It stores configuration and moderation records so the next ban is not starting from zero. This page is the honest version of that.

what this is for

This is for the official KozzyX Discord bot — the app you invite from this site, client id 1544122867296510032, currently shown as KozzyX (archived). The website sits with the same person.

Discord has its own privacy policy, and that still applies. If you run a copy of the code yourself, that copy is yours, and you are the one responsible for it. This page is only for the official bot.

Using the bot also means you agree to the terms.

who to write to

KozzyX is a privately run Discord app. Questions, deletion requests, and anything else about this page can go to ckazros@kozzyx.org, Discord ckazros, or the Discord server.

Include your Discord user id, and the server id if this is about a guild. Please don’t paste case files, tickets, or tokens into a public channel.

what it collects

Only what it needs to run the features you turned on in that server.

  • Discord idsUser, role, channel, and server ids that a command, event, or setting already touched. Display names come along with the message Discord sent.
  • moderation recordsWarns, bans, tempbans, kicks, timeouts, cases, appeals, and related reasons when staff provide them. Audit-log plugin data if that plugin is on.
  • server configurationWelcome/goodbye text, embed colors, ticket and case channels, verification, self-role menus, plugins, automations, custom commands, autoresponders, and similar guild settings.
  • community featuresGiveaway entries, poll data Discord already has, reminders, birthdays, AFK notes, booster-role links, invite-join tracking, and dynamic voice-channel records.
  • ticketsOpen-ticket metadata. There are no saved transcripts. Three tickets per hour, per the bot’s own cap.
  • dashboard loginIf you self-host the control center, Discord OAuth is used to see who you are and which servers you can manage. This public website does not run that login.
  • mail you send usIf you email or DM the operator, that message is just a message. We keep what we need to answer it.

It does not scrape every channel it can see. Ordinary chat is not stored unless a feature you enabled needs that message (autoresponder, automations, and similar).

why it keeps any of this

To apply the next moderation action. To remember the case. To keep the ticket panel and the verification button working after a restart. To run a giveaway you started.

We do not sell this. We do not run ads against it. We do not build a marketing list out of your cases.

how storage works

Guild data lives in a local SQLite file on the host (data/database.sqlite). It is keyed by server. Two servers do not share cases.

Please don’t send passwords, tokens, private keys, or anything you would not want in a mod log. If you already did, have the server owner run /data_deletion_request, or write us.

who else sees it

Discord already has the message, the member list, and the audit log. That is their platform, their rules.

Email alerts about the bot going down go through the SMTP settings on the host, to the operator. They are about the process, not your tickets.

We are not Discord. Their policies apply to what passes through them.

how long it stays

Guild records stay until a command changes them, the server owner wipes the guild with /data_deletion_request, the bot leaves and we delete leftover data later, or the host file is removed.

Temporary bans expire when their timer says so.

Backups of the host can hold a copy of the SQLite file for as long as those backups exist. Treat that file like a mod log, because it is.

your choices

If you don’t want a record, don’t use the bot. Kicking it stops new collection in that server. It does not, by itself, wipe what is already stored.

Server owners can run /data_request to see counts, and /data_deletion_request to delete that server’s stored rows. That does not erase Discord’s own messages, other servers, or the operator’s email inbox.

If that is not enough, email ckazros@kozzyx.org with the Discord user id and server id.

this website

The site is static pages on GitHub Pages. The menu JavaScript does not set cookies. There is no analytics tag on these pages.

The host and the browser still do normal web things: a request log on their side, a cached file on yours. We do not use that to profile you. Contact is just email.

age

You need a Discord account, and you need to be old enough for Discord. That means 13 or older. Please don’t use the bot if you are under 13.

the official bot vs running it yourself

Self-hosting means your SQLite file, your keys, your users, and your own privacy policy. The official bot is the one invited from this site.

We can change limits and where the file lives. If that changes what we collect in a way that matters, this page will say so.

if this page changes

If this page changes, the new text applies once it is up. The date at the top is when that happened. Keeping the bot after that is agreement to the new policy.

Questions go to ckazros@kozzyx.org, Discord ckazros, or the Discord server.
